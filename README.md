### Reflexão

Ao analisar os dez perfis no GitHub, percebi que um perfil
bem organizado pode fazer bastante diferença na forma como um profissional
é apresentado. Uma coisa que apareceu em vários perfis foi uma descrição
simples, falando sobre a área de atuação e as principais tecnologias
utilizadas. Também achei interessante a utilização dos projetos fixados,
porque eles ajudam a mostrar rapidamente o que a pessoa sabe fazer.
Outro ponto que observei foi a importância dos arquivos README,
principalmente para explicar o objetivo dos projetos e como eles funcionam.
Alguns perfis também possuem links para LinkedIn, portfólio e outras
formas de contato. Percebi que não é necessário colocar muitas informações
para ter um perfil interessante, mas é importante escolher bem o que será
mostrado. Os projetos também precisam estar organizados e ter nomes e
descrições fáceis de entender. Com essa pesquisa, percebi que meu GitHub
pode ser usado como uma forma de mostrar minha evolução na área de
programação. Por isso, pretendo melhorar a apresentação do meu perfil e
escolher meus melhores projetos para deixar em destaque. Também quero
melhorar os READMEs dos meus repositórios e deixar as informações mais
organizadas. Acredito que essas mudanças podem deixar meu GitHub mais
profissional e facilitar para outras pessoas entenderem minhas habilidades.
